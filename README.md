A nostalgic, retro vinyl record player web application celebrating the golden age of classic Hindi cinema music (1950s–1980s). Recreating the warm, crackling ambiance of listening to vintage transistor radios in an old-school Indian salon or chai tapri.

---

## ✨ Features

- 💽 **Interactive Vinyl Turntable**
  - Smooth mechanical tonearm that moves into place on playback.
  - Realistic rotating vinyl disc with concentric sound grooves and spinning album artwork.
- 🎨 **23 Dedicated Vintage Album Covers**
  - Unique vintage-styled album covers for every track, framed with ornate Indian gold/paisley borders and warm retro patina.
- 📻 **Dual-Audio Engine (Ambient Radio Static & Crackle)**
  - Optional ambient background layer simulating vintage radio static and vinyl needle crackle.
  - Independent volume controls for both music and ambient audio.
- 📜 **Slide-Out Playlist Drawer**
  - Modern glassmorphic sliding drawer displaying all 23 tracks with thumbnails, artist metadata, and animated equalizer bars for active tracks.
- 🎛️ **Full Playback Controls**
  - Interactive scrubbable progress bar with real-time timestamp display (`current / total`).
  - Next track, previous track, play/pause, volume slider, and instant mute toggle.
- ⏰ **Retro Digital HUD**
  - Integrated vintage LED-style live clock keeping real-time hours, minutes, and seconds.
- 📱 **Fully Responsive**
  - Crafted with fluid glassmorphism and mobile-first CSS, optimized across desktops, tablets, and smartphones.
- ⚡ **Production & Vercel Ready**
  - Custom Vite build script that bundles `app.js` and automatically copies all audio tracks and album art to the `dist/` production folder.

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- Git

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sumitchaudhari-rgb/papa_ka_jamana.git
   cd papa_ka_jamana
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173/`.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The compiled, fully self-contained bundle will be created in the `dist/` directory.

## 🌐 Deploying to Vercel

This repository is pre-configured for seamless 1-click deployment on [Vercel](https://vercel.com/):

1. **Push your code to GitHub:**
   ```bash
   git add .
   git commit -m "Deploy Papa Ka Jamana to Vercel"
   git push origin main
   ```
2. **Import Project on Vercel:**
   - Log into [vercel.com](https://vercel.com).
   - Click **Add New...** → **Project**.
   - Select the `papa_ka_jamana` repository.
   - Framework preset will automatically detect **Vite**.
   - Leave the default settings:
     - **Build Command:** `npm run build`
     - **Output Directory:** `dist`
     - **Install Command:** `npm install`
3. Click **Deploy**. Your nostalgic music player will be live worldwide! 🚀
